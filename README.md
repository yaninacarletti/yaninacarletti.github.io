# Yanina Carletti — Portfolio

A professional portfolio built with **Astro**, showcasing end-to-end projects in **Data Engineering, Data Analytics and Machine Learning**.

**Live Portfolio:** https://yaninacarletti.github.io

## About

This repository contains the source code of my personal portfolio website, designed to present technical projects, professional experience and data-related work in a clean and recruiter-friendly format.

The site includes six case studies covering predictive modeling, ETL pipelines, forecasting, recommendation systems, customer segmentation and data quality workflows.

## Featured Projects

### Detection of Churn

End-to-end machine learning pipeline including feature engineering, model training, evaluation and SHAP-based explainability.

### Customer Segmentation

Unsupervised learning workflow using PCA and K-Means to identify customer groups and support marketing decisions.

### Sales Forecasting

Time-series forecasting models for business planning and sales prediction.

### Recommendation System

Collaborative filtering recommendation engine for personalized product suggestions.

### ETL Airplane Tickets

Automated ETL pipeline built with Python, SQL, Airflow and Docker.

### Data Quality

Reusable preprocessing and validation workflow for improving dataset reliability.

## Local Development

Clone the repository and install dependencies:

```bash
git clone https://github.com/yaninacarletti/yaninacarletti.github.io.git
cd yaninacarletti.github.io
npm install
```

Start the development server:

```bash
npm run dev
```

Build the project:

```bash
npm run build
```
